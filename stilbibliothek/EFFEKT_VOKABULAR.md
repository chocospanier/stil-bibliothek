# Effekt-Vokabular

> Feste Kennungen für Techniken, damit sich Stile vergleichen und zählen lassen. Jede Stil-Karte listet ihre Effekte nur mit diesen Kennungen. Fehlt eine Technik: in der Karte als `neu:<kennung>` mit einem Satz Erklärung eintragen; beim Bündeln wandert sie hierher. Stand 17.10.2026: Grundstock plus 99 Kennungen aus der Auszählung von 101 Stil-Karten, Synonyme zusammengelegt, dazu 7 Kennungen der Familie erklaerstimme.

## Schnitt und Übergang
| Kennung | Bedeutung |
|---|---|
| `harter-schnitt` | Bild springt ohne Übergang |
| `match-cut` | Form, Bewegung oder Pose läuft über den Schnitt weiter |
| `blitzbild` | ein bis drei Vollbilder in Weiß, Schwarz oder Akzentfarbe als Schnitt |
| `blende` | Überblendung, Weiß- oder Schwarzblende |
| `wischer` | Reißschwenk oder Bewegungsunschärfe trägt den Schnitt |
| `zoom-durchflug` | Kamera fliegt in ein Detail hinein, dahinter das nächste Bild |
| `masken-wechsel` | neues Bild erscheint in einer Form (Kreis, Figur, Buchstabe) |
| `filmriss` | Filmbrand, Lichtleck oder Perforation als Übergang |
| `glitch-uebergang` | Pixelversatz, Datamosh oder Zeilenriss als Schnitt |
| `stottern` | ein Bild steht zwei bis vier Takte lang, springt, steht wieder |
| `tempo-rampe` | Zeitlupe und Zeitraffer im selben Shot, meist auf den Beat |
| `standbild-halt` | Bild friert ein, oft mit Kontur oder Text darauf |
| `rueckwaerts` | Clip läuft rückwärts oder pendelt |
| `wiederholung` | dasselbe Bild mehrfach nebeneinander oder hintereinander (Triptychon, Echo) |
| `split-screen` | zwei oder mehr Bilder gleichzeitig in festen Feldern |
| `raster-collage` | viele Kacheln im Gitter, wechseln einzeln |
| `bild-im-bild` | Rahmen, Fenster, Polaroid oder Bildschirm im Bild |
| `wort-schnitt` | Schnitt sitzt auf gesprochenem Wort oder Text, nicht auf dem Beat |
| `sprungschnitt` | eine Einstellung in Stücke geschnitten, die Figur springt im selben Bild |
| `schwarzbild` | kurzes schwarzes Vollbild als Satzzeichen zwischen zwei Bildern |
| `unschaerfe-blitz` | ein bis drei völlig unscharfe Bilder desselben Motivs als Satzzeichen |
| `vorhang` | Bühnenvorhang öffnet und schließt als Übergang |
| `licht-an-aus` | dieselbe Einstellung im Takt hell und dunkel geschnitten |
| `farbkipp` | Wechsel zwischen Schwarzweiß und Farbe als Ereignis, meist auf dem Drop |
| `behandlungs-wechsel` | die Bildbehandlung (Farbe, Stil, Hintergrund) wechselt im festen Takt bei laufendem Bild oder je Shot |
| `fenster-tanz` | der Bildausschnitt ändert im Takt Form und Kippung, der Inhalt bleibt fest |
| `kreisfenster` | rundes Fenster oder Schlüsselloch zeigt ein anderes oder unverfremdetes Bild |
| `querband` | Bild nur in einem waagerechten Band auf Schwarz, auch als Wechsel zwischen Vollbild und Band |
| `stop-motion` | Figur oder Grafik bewegt sich auf Zweiern oder Dreiern statt flüssig, auch niedrige Bildrate |
